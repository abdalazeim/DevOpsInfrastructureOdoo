# Odoo Multi-Version Deployment - جميع طرق التشغيل (لينكس أوبونت فقط)

## موقع المشروع
`D:\Project Django Frameworks\DevOpsInfrastructureOdoo\Infrastructure-manage-T\deployment\Odoo-MultiVersion-Deployment\scripts\`

> **ملاحظة هامة**: هذا النظام مبرمج بالكامل لنظام **لينكس أوبونت** (الإصدارات 20, 22, 24 وما فوق). لا يحتوي على أي مكونات خاصة بنظام ويندوز. المسار أعلاه هو مسار تخزين الملفات على قرص ويندوز فقط لتسهيل التعديل، ولكن التشغيل الفعلي يتم على خادم لينكس أوبونت.

## الطريقة 1: التشغيل السريع (أمر واحد)

افتحTerminal على خادم لينكس أوبونت ونفذ:

```bash
# الانتقال إلى مجلد السكربتات
cd /opt/Odoo-MultiVersion-Deployment/scripts

# تشغيل السكربت الرئيسي بصلاحيات الجذر (يقوم بتشغيل bootstrap تلقائياً)
sudo bash launch-odoo-infra.sh
```

---

## الطريقة 2: التشغيل بالتدرج (خطوة بخطوة)

### الخطوة الأولى: تثبيت الملاحقات وإعداد البيئة
```bash
sudo bash bootstrap-odoo-infra.sh
```

### الخطوة الثانية: تشغيل المشروع وتثبيت Odoo 17 و 19
```bash
sudo bash launch-odoo-infra.sh
```

---

## الطريقة 3: التشغيل اليدوي لكل مكون

### تثبيت Odoo 17 فقط (نسختان)
```bash
sudo bash install-odoo17.sh
```

### تثبيت Odoo 19 فقط (نسختان)
```bash
sudo bash install-odoo19.sh
```

### فحص صحة الخدمات
```bash
sudo bash health-check.sh instance1 8069 8072
sudo bash health-check.sh instance2 8069 8072
```

### أخذ نسخة احتياطية
```bash
sudo bash backup.sh instance1 odoo17 /data/backups/odoo17
sudo bash backup.sh instance2 odoo17 /data/backups/odoo17
sudo bash backup.sh instance1 odoo19 /data/backups/odoo19
sudo bash backup.sh instance2 odoo19 /data/backups/odoo19
```

### استعادة نسخة احتياطية
```bash
sudo bash restore.sh odoo17-instance1-20261104 odoo17 instance1 existing
```

### التحقق من سلامة النسخ الاحتياطية
```bash
sudo bash verify-backups.sh /data/backups
```

### عرض جميع النسخ الاحتياطية المتوفرة
```bash
sudo bash list-backups.sh /data/backups
```

### نسخ إعدادات نظام أوبونت
```bash
sudo bash backup-system-config.sh
```

### استعادة إعدادات نظام أوبونت
```bash
sudo bash restore-system-config.sh 2026-11-04_020000
```

## الطريقة 4: عبر Jenkins

افتح لوحة تحكم Jenkins على خادم اللينكس وشغل Lines الأنابيب التالية:

| Line الأنابيب | المسار | الغرض |
|--------------|--------|-------|
| Install Odoo 17 | `Jenkins/install-odoo17.Jenkinsfile` | تثبيت نسختي Odoo 17 |
| Install Odoo 19 | `Jenkins/install-odoo19.Jenkinsfile` | تثبيت نسختي Odoo 19 |
| Backup | `Jenkins/backup.Jenkinsfile` | أخذ نسخة احتياطية |
| Restore | `Jenkins/restore.Jenkinsfile` | استعادة نسخة احتياطية (يتطلب تأكيد) |
| Verify Backups | `Jenkins/verify-backups.Jenkinsfile` | التحقق من سلامة النسخ |
| System Config Backup | `Jenkins/system-config-backup.Jenkinsfile` | نسخ إعدادات نظام أوبونت |

## الطريقة 5: عبر Ansible Playbooks مباشرة

```bash
# الانتقال إلى مجلد المشروع
cd /opt/Odoo-MultiVersion-Deployment

# تثبيت Odoo 17
ansible-playbook -i ansible/inventory/hosts.ini -e @versions/odoo17.yml ansible/playbooks/install-odoo17.yml

# تثبيت Odoo 19
ansible-playbook -i ansible/inventory/hosts.ini -e @versions/odoo19.yml ansible/playbooks/install-odoo19.yml

# أخذ نسخة احتياطية
ansible-playbook -i ansible/inventory/hosts.ini ansible/playbooks/backup.yml

# التحقق من النسخ الاحتياطية
ansible-playbook -i ansible/inventory/hosts.ini ansible/playbooks/verify.yml

# نسخ إعدادات النظام
ansible-playbook -i ansible/inventory/hosts.ini ansible/playbooks/system-config-backup.yml
```

## ملاحظة هامة حول الصلاحيات

يجب تشغيل جميع السكربتات بصلاحيات **الجذر (sudo/root)** لأنها تقوم بـ:
- تثبيت حزم النظام (Docker, Ansible, Python3, Git)
- إنشاء دوائر Docker وصلاحيات الشبكة
- إعداد مجلدات البيانات (`/data/`) والإعدادات (`/opt/`)
- تشغيل وإدارة حاويات Docker

---

## ملفات السكربتات في المجلد

| الملف | الغرض |
|-------|-------|
| `bootstrap-odoo-infra.sh` | تثبيت الملاحقات وإعداد البيئة الأساسية (لينكس فقط) |
| `launch-odoo-infra.sh` | تشغيل المشروع بالكامل (يشغل bootstrap تلقائياً) |
| `install-odoo17.sh` | تثبيت Odoo 17 (نسختان مستقلتان) |
| `install-odoo19.sh` | تثبيت Odoo 19 (نسختان مستقلتان) |
| `health-check.sh` | فحص صحة الخدمات والحاويات |
| `backup.sh` | أخذ نسخة احتياطية لـ Odoo |
| `restore.sh` | استعادة نسخة احتياطية لـ Odoo |
| `verify-backups.sh` | التحقق من سلامة النسخ الاحتياطية |
| `list-backups.sh` | عرض جميع النسخ الاحتياطية المتوفرة |
| `backup-system-config.sh` | نسخ إعدادات نظام أوبونت (شبكة, SSH, Docker, إلخ) |
| `restore-system-config.sh` | استعادة إعدادات نظام أوبونت |
