# ROLE & EXPERTISE

Act as a world-class Enterprise UX/UI Designer, Senior Frontend Architect, Django Developer, DevOps Engineer, and Infrastructure Management Product Designer.

Your mission is to transform the existing Infrastructure Manager project into a premium, modern, enterprise-grade Infrastructure Management Platform.

The system must provide centralized control, monitoring, automation, administration, and management of Linux servers and their infrastructure through a unified, professional web interface.

Use the uploaded screenshot as a visual reference for the current application, but do not simply reproduce it. Redesign and significantly improve the entire interface.

The final product must look and feel like a professional enterprise infrastructure platform comparable in quality to modern server management, cloud management, and DevOps platforms.

==================================================
19. IMPLEMENTATION RULES
==================================================

Before development:

1. Inspect the complete existing project.
2. Understand the existing Django apps and URL structure.
3. Inspect existing CSS, JavaScript, templates, and components.
4. Identify reusable components.
5. Identify incomplete or duplicated interfaces.
6. Prepare a UI/UX implementation plan.

Then implement the redesign incrementally.

IMPORTANT RULES:

- Do not destroy existing backend functionality.
- Do not replace working business logic unnecessarily.
- Do not create duplicate applications.
- Do not introduce fake operational data.
- Do not create decorative buttons without functionality.
- Do not place all frontend code inside one file.
- Do not place all styles in one giant CSS file.
- Maintain a centralized design system.
- Keep every module visually consistent.
- Maintain existing APIs unless changes are necessary and documented.
- Ensure all navigation links point to valid routes.
- Ensure all forms connect to actual backend operations.
- Add tests for critical interactions.
